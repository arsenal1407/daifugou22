# 大富豪オンライン

合言葉でマッチルームを作って2〜10人でオンライン対戦できる大富豪です。Node.js + Socket.io 製。

## 特殊ルール(部屋ごとにON/OFF可能)

| ルール | 内容 |
|---|---|
| 通常革命 | 同ランク4枚以上で場の強弱が反転 |
| 階段 | 同スート3枚以上の連番を役として出せる |
| 階段革命 | 階段5枚以上で強弱反転(「階段」ON時のみ意味を持つ) |
| 11バック | ジャックを含む役を出すと、場が流れるまで強弱反転 |
| 8切り | 8を含む役を出すと即座に場が流れ、同じ人がもう一度出せる |
| 7渡し | 7を含む役を出した枚数分、好きな相手にカードを渡す |
| 10捨て | 10を含む役を出した枚数分、手札を捨てる |
| スペード3返し | 場にジョーカー単体が出ているとき、スペード3単体で返せる |
| 階級制 | ラウンド終了時に大富豪〜大貧民の階級がつき、次ラウンド開始時に強制カード交換が発生 |

## 前提として簡略化している点

- ジョーカーはペアや階段には組み込めず、単体プレイのみ対応(最強の一枚として扱われます)
- 場を縛るスート縛り(しばり)ルールは未実装です
- 対戦中に切断したプレイヤーは自動パスされず、その場に留まります(手動で再接続すれば復帰できます)
- カード交換の「大富豪が返すカード」は本人が自由に選べます(制限なし)

必要であれば追加で実装できますので、気軽に相談してください。

## ローカルでの起動方法

```bash
npm install
npm start
```

`http://localhost:3000` を開くと遊べます。同じネットワーク内であれば `http://<自分のIP>:3000` で他の端末からもアクセスできます。

## デプロイ方法(Render の場合)

1. このフォルダをGitリポジトリにする(GitHubにpushしておくとスムーズです)
2. [Render](https://render.com/) にログインし「New +」→「Web Service」を選択
3. リポジトリを選択し、以下を設定
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free でOK
4. デプロイ完了後に発行されるURL(例: `https://your-app.onrender.com`)を友達に共有すればOKです

Railway の場合もほぼ同様で、リポジトリを接続して `npm install` → `npm start` が走るようにするだけで動きます。

※ 無料プランは一定時間アクセスがないとスリープすることがあります。対戦前に一度アクセスして起こしておくとスムーズです。

## 遊び方

1. 参加者全員が同じURLを開く
2. 名前と「合言葉」(部屋を識別するキーワード)を入力して「参加 / 部屋を作る」を押す
   - 最初にその合言葉を使った人がルームのホストになり、特殊ルールの設定とゲーム開始を行えます
3. 全員揃ったらホストがルールを設定して「ゲーム開始」
4. 自分の番になったら手札からカードをタップして選択し「出す」、出せなければ「パス」
5. 階級制がONの場合、ラウンド終了後にホストが「次のラウンド開始」を押すとカード交換を経て次のラウンドが始まります

## 動作確認について

`tests/test_game.js` に、役の判定・特殊ルールの発動条件・ラウンド終了処理などのロジックを検証する簡易テストスクリプトを同梱しています。

```bash
node tests/test_game.js
```
